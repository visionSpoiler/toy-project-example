# notes

이 폴더는 프로젝트를 진행하면서 배운 것을 정리하는 학습 노트 전용 공간입니다.

## 작성 방식

- 새로 정리할 내용이 생기면 `notes/` 에 `.md` 파일을 하나 만든다.
- 파일명은 내용을 알 수 있게 짧게 짓는다. (예: `form-validation.md`, `local-storage.md`)
- 폴더로 영역(서비스/개발/데이터)을 나누지 않는다. 하나의 기능/주제를 다루는 내용에 서비스 관점과 개발 관점이 함께 섞여도 괜찮다.
- 필요하면 파일 안에서 섬션(## 서비스 관점, ## 개발 관점, ## 데이터 관점)으로만 구분한다.
- 새 파일을 만들면 `index.md` 에 한 줄 요약과 날짜를 추가한다.

## 템플릿 (노트 파일 안에서 사용)

```md
# 제목

- 작성일: YYYY-MM-DD
- 관련 기능/파일:

## 배운 것

## 서비스 관점 (선택)

## 개발 관점 (선택)

## 데이터 관점 (선택)

## 참고
```
